> **Applies to:** CODAP v3 · **Verified:** 2026-10-27

[CODAP Data Interactive Plugin API](https://github.com/concord-consortium/codap/wiki/CODAP-Data-Interactive-Plugin-API)
wiki page, which is now frozen as the reference for CODAP v2. The table below lists every
section of that page and where its subject is covered here, so a link to one of its sections is
one step from the v3 documentation. Sections are indented as they are nested on the wiki page.
